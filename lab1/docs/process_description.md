# Процесс: «Заказ еды в ресторане с доставкой»

**Название процесса:** Доставка еды из ресторана клиенту.

**Участники (роли):**
- **Клиент** — выбирает блюда, оплачивает заказ, подтверждает получение.
- **Система (сайт/приложение)** — проверяет наличие, рассчитывает стоимость, принимает оплату, назначает курьера.
- **Ресторан** — подтверждает заказ и готовит блюда.
- **Курьер** — забирает заказ и доставляет его клиенту.

**Основные шаги:**
1. Клиент выбирает блюда и оформляет заказ.
2. Система проверяет наличие всех блюд в меню ресторана.
3. **Ветвление 1:** если хотя бы одного блюда нет в наличии — система предлагает клиенту замену, и процесс возвращается к шагу проверки.
4. Система рассчитывает итоговую стоимость и принимает оплату.
5. **Ветвление 2:** если оплата не прошла — заказ отменяется, процесс завершается.
6. Ресторан принимает заказ в работу.
7. **Параллельно** запускаются два потока: ресторан готовит блюда, а система назначает курьера на заказ.
8. После завершения обоих потоков курьер забирает заказ из ресторана.
9. Курьер доставляет заказ клиенту.
10. Клиент подтверждает получение — процесс успешно завершён.
